COUNTING RULES

Only the next whole number is accepted.
The same member cannot count twice in a row.
Invalid messages can be deleted automatically.
A mistake can reset the current count while preserving the high score.

STARBOARD RULES

HIT counts only the configured reaction.
Bot reactions are ignored.
Self-reactions are ignored unless explicitly enabled.
Posts are created when the threshold is reached, updated as the count changes,
and removed if the count drops below the threshold.
The configured reaction is functional; HIT does not add decorative emojis to messages.
